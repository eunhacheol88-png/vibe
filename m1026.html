선택한 기능을 합친 프롬프트

대시보드 고도화 프롬프트
현재 정상 작동하는 '나의 생활비 계산기'를 재무 관리 대시보드 형태로 고도화해 줘.

[원하는 화면]
- 왼쪽 메뉴 또는 상단 메뉴: 대시보드, 거래 내역, 예산 관리
- 상단 요약 카드: 전체 수입, 전체 지출, 현재 잔액
- 메인 영역: 월별 지출 흐름 차트, 카테고리별 지출 차트
- 거래 내역: 날짜·항목·분류·금액·수입/지출을 확인하고 등록·수정·삭제
- 월별 또는 기간별 필터

[데이터 동작]
- 요약 카드와 그래프는 실제 등록된 기록으로 계산해 줘.
- 수입은 더하고 지출은 빼서 잔액을 계산해 줘.
- 거래를 등록·수정·삭제하면 카드·차트·목록이 함께 갱신되어야 해.
- 빈 데이터 화면에는 0원 또는 안내를 보여 줘. 가상 값을 실제 기록인 것처럼 표시하지 마.

[화면 오류 예방]
- 새 거래 입력 영역이 거래 목록을 가리거나 겹치지 않도록 해 줘.
- 목록이 길어져도 스크롤이 정상 동작하게 해 줘.
- PC와 모바일에서 반응형으로 보여 줘.

[유지]
- 기존 거래 기록과 정상 작동 기능 보존
- 별도 외부 API·데이터베이스 연결 없이 현재 Canvas에서 실행 가능하도록 구성
- 수정 후 합계·잔액·차트·등록·수정·삭제 테스트 방법 안내
고도화 포인트 앱이 이미 수입·지출을 구분하거나 대시보드로 만들어졌다면 중복 구현을 요청하지 말고 부족한 화면 요소만 요청합니다.

STEP 05
오류가 나면 증상을 구체적으로 설명하기
해결을 요구하기 전에 무엇이 작동하지 않는지부터 구분합니다. 아래에서 상황을 선택하고 추가 설명을 입력하세요.
오류 해결 프롬프트
실제 발생했던 화면 겹침 문제
증상
‘새 거래 내역 기록’ 카드가 ‘거래 내역 목록’을 덮어버림. 목록 일부가 보이지 않고 정상 스크롤되지 않음.
확인할 부분
입력 폼·거래 목록의 배치, 높이 제한, 스크롤 영역, 겹침 순서. 원인을 확정하기 전 전체 구조 변경은 피함.
화면 겹침 전용 수정 프롬프트
현재 '나의 생활비 계산기' 대시보드에서 화면 배치 문제가 발생했어.

[실제 증상]
'새 거래 내역 기록' 입력 영역이 '거래 내역 목록'을 가려서 목록을 보거나 스크롤하기 어려워.

[수정 요청]
- 두 영역의 레이아웃을 점검하고 겹치지 않도록 고쳐 줘.
- 필요하다면 카드 높이·overflow·grid/flex 배치를 수정해 줘.
- 모바일에서는 세로 배치로 자연스럽게 전환해 줘.
- 거래 목록이 길어져도 전체 항목을 볼 수 있어야 해.
- 현재 거래 데이터·계산·차트·버튼 기능은 유지해 줘.
- 실제 원인 확인 없이 z-index만 무작정 올리지 마.
- 수정 후 긴 거래 목록을 넣어 스크롤이 정상 작동하는지 확인해 줘.
STEP 06
마지막 — 성공한 버전으로 정리하기
여러 번 개선한 대화보다 중요한 것은 현재 정상 작동하는 웹앱입니다. 기능을 확인하고 마지막 정상 코드를 보관합니다.
최종 성공 버전 점검·정리 프롬프트
현재 '나의 생활비 계산기'에서 생활비 관리 대시보드까지 단계적으로 발전시킨 앱이 정상적으로 작동해.

이제 최종 성공 버전으로 정리해 줘.

[최종 확인]
1. 거래 등록·수정·삭제가 모두 동작하는지 확인해 줘.
2. 수입·지출·잔액 계산이 정확한지 검증해 줘.
3. 필터를 적용하면 거래 목록, 요약 카드, 차트의 기준이 일관된지 확인해 줘.
4. 거래가 없을 때도 오류 없이 표시해 줘.
5. 거래 등록 영역과 목록이 겹치지 않고 스크롤 가능한지 확인해 줘.
6. 모바일에서도 사용 가능한지 확인해 줘.
7. 현재 저장 방식과 새로고침 후 유지 여부를 사실대로 설명해 줘.

[최종 정리]
- 정상 작동하는 현재 버전의 코드 전체를 보존할 수 있게 해 줘.
- 앱 이름, 핵심 기능, 사용 방법을 한글로 간단히 정리해 줘.
- 수정 이력보다 '현재 성공한 기능'을 기준으로 최종 결과를 설명해 줘.
- 새로운 기능이나 외부 데이터베이스를 임의로 추가하지 마.
- 실제 검증하지 않은 항목은 성공이라고 단정하지 마.
최종 산출물에 남길 것
현재 정상 앱→기능 확인→최종 코드 보관→앱 사용 안내
최종 성공 기준 실제 거래를 입력해 사용할 수 있는 대시보드이며, 핵심 기능이 작동하고, 어떤 데이터가 어디에 저장되는지 설명할 수 있는 상태입니다.
