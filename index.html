용어를 외우는 자료가 아닙니다. 원하는 화면을 AI에게 더 정확하게 설명하고 싶을 때 찾아보세요. 한글 설명을 먼저 보고 필요할 때 영어 원어를 참고하면 됩니다.

수업에서 이렇게 사용하세요.
① 화면을 봅니다 → ② 마음에 안 드는 부분을 찾습니다 → ③ 아래에서 비슷한 문제나 용어를 찾습니다 → ④ 예시 프롬프트를 복사합니다 → ⑤ 내 상황에 맞게 조금 바꿉니다 → ⑥ AI가 수정한 실제 화면을 다시 확인합니다.
가장 중요한 원칙
“전체적으로 예쁘게 해줘”보다 “현재 내용은 유지하고 카드 사이 간격만 넓혀줘”처럼 무엇을 유지하고 무엇만 바꿀지 말하면 수정 범위를 더 분명하게 전달할 수 있습니다.

📘 웹디자인 용어 + 바로 쓰는 프롬프트

구조

헤더

Header

웹사이트 맨 위쪽의 큰 영역입니다. 로고, 사이트 이름, 메뉴 등이 들어가는 경우가 많습니다.

이럴 때 찾아보세요
사이트 맨 위가 정리되지 않아 보일 때
현재 콘텐츠와 기능은 유지하고 웹사이트 상단 영역을 정리해줘. 사이트 이름과 이동 메뉴가 한눈에 들어오도록 배치해줘.
구조

상단 이동 메뉴

Navigation

사용자가 원하는 콘텐츠나 페이지로 이동할 수 있게 해주는 메뉴입니다.

이럴 때 찾아보세요
메뉴를 만들거나 이동이 제대로 되는지 점검할 때
현재 디자인은 유지하고 상단에 이동 메뉴를 만들어줘. 메뉴를 누르면 해당 콘텐츠로 실제 이동할 수 있게 연결해줘.
구조

첫 화면 대표 영역

Hero Section

웹사이트를 열었을 때 처음 크게 보이는 대표 영역입니다. 핵심 제목, 설명, 이미지 등이 들어갑니다.

이럴 때 찾아보세요
첫 화면이 밋밋하거나 핵심이 안 보일 때
현재 콘텐츠는 유지하고 첫 화면에서 핵심 제목과 설명이 먼저 눈에 들어오도록 대표 영역을 다시 구성해줘.
구조

콘텐츠 영역

Section

비슷한 내용을 하나의 덩어리로 묶은 영역입니다.

이럴 때 찾아보세요
내용이 뒤섞여 보일 때
현재 내용은 삭제하지 말고 비슷한 내용끼리 영역을 나눠서 읽기 쉽게 구성해줘.
구조

카드

Card

이미지, 제목, 설명 등을 하나의 작은 상자처럼 묶어 보여주는 방식입니다.

이럴 때 찾아보세요
여러 정보를 반복해서 깔끔하게 보여주고 싶을 때
현재 콘텐츠는 유지하고 반복되는 정보를 카드 형태로 정리해줘. 카드마다 제목과 설명이 쉽게 구분되게 해줘.
구조

행동 유도 영역

CTA

사용자에게 클릭, 신청, 문의, 더 보기 같은 행동을 유도하는 부분입니다.

이럴 때 찾아보세요
사용자가 다음에 무엇을 해야 할지 분명하게 만들 때
사용자가 다음 행동을 쉽게 알 수 있도록 필요한 위치에 행동 유도 버튼을 배치해줘. 불필요한 버튼은 추가하지 마.
구조

하단 영역

Footer

웹사이트 가장 아래쪽 영역입니다. 연락처, 저작권, 추가 링크 등이 들어갈 수 있습니다.

이럴 때 찾아보세요
페이지 끝을 정리하고 싶을 때
현재 디자인과 어울리게 웹사이트 하단 영역을 정리해줘. 꼭 필요한 정보만 간결하게 배치해줘.
디자인

배치

Layout

화면에서 제목, 이미지, 카드, 메뉴 같은 요소를 어디에 놓을지 정하는 방식입니다.

이럴 때 찾아보세요
화면 구성이 어수선할 때
현재 콘텐츠는 유지하고 전체 배치를 더 정돈되게 수정해줘. 중요한 내용이 먼저 보이도록 구성해줘.
디자인

정렬

Alignment

글자나 이미지의 시작선과 위치를 맞춰 화면을 정돈하는 것입니다.

이럴 때 찾아보세요
요소들이 삐뚤삐뚤하거나 어수선해 보일 때
현재 콘텐츠와 크기는 유지하고 제목, 본문, 카드의 정렬을 일관되게 맞춰줘.
디자인

중요도 표현

Visual Hierarchy

사용자가 무엇을 먼저 보고 다음에 무엇을 볼지 시선의 순서를 만드는 것입니다.

이럴 때 찾아보세요
모든 글자가 비슷해 무엇이 중요한지 모르겠을 때
가장 중요한 제목이 먼저 보이고 다음으로 설명과 세부 내용이 보이도록 글자 크기와 굵기, 간격을 조정해줘.
디자인

글자 디자인

Typography

글꼴, 글자 크기, 굵기, 줄 간격 등을 조절해 읽기 쉽고 분위기에 맞게 만드는 것입니다.

이럴 때 찾아보세요
글자가 촌스럽거나 읽기 힘들 때
현재 콘텐츠는 유지하고 제목과 본문의 글자 크기, 굵기, 줄 간격을 조정해서 읽기 편하게 만들어줘.
디자인

색상 조합

Color Palette

웹사이트에서 함께 사용할 주요 색상을 정한 조합입니다.

이럴 때 찾아보세요
색이 너무 많거나 통일감이 없을 때
현재 구조와 콘텐츠는 유지하고 전체 색상을 3~4개의 조화로운 색상 중심으로 정리해줘.
디자인

대비

Contrast

글자와 배경처럼 서로 다른 요소의 차이를 분명하게 만드는 것입니다.

이럴 때 찾아보세요
글자가 배경에 묻혀 잘 안 보일 때
현재 색상 분위기는 최대한 유지하면서 글자와 배경의 대비를 높여 내용을 더 잘 읽을 수 있게 수정해줘.
디자인

여백

Spacing

요소와 요소 사이의 공간을 조절하는 개념입니다.

이럴 때 찾아보세요
전체적으로 화면이 답답해 보일 때
현재 콘텐츠는 유지하고 각 영역과 요소 사이의 여백을 조금 더 넓혀 답답하지 않게 만들어줘.
디자인

빈 공간

Whitespace

아무것도 없는 공간을 의도적으로 남겨 내용이 편하게 보이도록 하는 것입니다.

이럴 때 찾아보세요
화면에 너무 많은 것이 붙어 있을 때
현재 콘텐츠는 삭제하지 말고 요소 사이에 충분한 빈 공간을 만들어 핵심 내용에 집중할 수 있게 해줘.
디자인

바깥 여백

Margin

상자나 요소의 바깥쪽에 생기는 공간입니다.

이럴 때 찾아보세요
카드끼리 너무 붙어 있을 때
카드의 내용은 유지하고 카드와 카드 사이의 바깥 여백을 넓혀줘.
디자인

안쪽 여백

Padding

상자 테두리와 그 안의 글자나 이미지 사이의 공간입니다.

이럴 때 찾아보세요
카드 안 글자가 테두리에 너무 붙어 있을 때
카드 크기와 내용은 최대한 유지하고 카드 안쪽 여백을 조금 넓혀줘.
움직임·효과

애니메이션

Animation

웹페이지의 요소에 움직임이나 변화를 주는 큰 개념입니다. 페이드인, 슬라이드인, 확대 같은 여러 효과를 포함합니다.

이럴 때 찾아보세요
화면에 적당한 움직임을 추가하고 싶을 때
현재 콘텐츠와 기능은 유지하고 주요 요소에 자연스러운 애니메이션을 추가해줘. 움직임은 과하지 않게 하고 읽기와 사용을 방해하지 않게 해줘.
움직임·효과

페이드인

Fade-in

처음에는 보이지 않거나 흐리던 요소가 서서히 나타나는 효과입니다.

이럴 때 찾아보세요
제목이나 콘텐츠가 부드럽게 등장하게 하고 싶을 때
현재 콘텐츠와 디자인은 유지하고 주요 제목과 콘텐츠가 자연스럽게 서서히 나타나는 페이드인 효과를 추가해줘. 너무 느리거나 과하지 않게 해줘.
움직임·효과

호버 효과

Hover Effect

마우스를 버튼이나 카드 위에 올렸을 때 색, 크기, 그림자 등이 변하는 효과입니다.

이럴 때 찾아보세요
버튼이나 카드가 선택 가능한 요소라는 것을 쉽게 보여주고 싶을 때
현재 디자인과 기능은 유지하고 카드와 버튼에 마우스를 올렸을 때 자연스럽게 반응하는 호버 효과를 추가해줘. 크기와 그림자 변화는 과하지 않게 해줘.
움직임·효과

확대 효과

Scale / Zoom

이미지나 카드가 살짝 커지면서 강조되는 효과입니다.

이럴 때 찾아보세요
마우스를 올린 카드나 이미지를 눈에 띄게 하고 싶을 때
현재 레이아웃은 유지하고 주요 카드나 이미지에 마우스를 올렸을 때 살짝 확대되는 효과를 추가해줘. 주변 배치가 흔들리지 않게 해줘.
움직임·효과

슬라이드인

Slide-in

콘텐츠가 화면의 옆이나 아래에서 자연스럽게 들어오는 효과입니다.

이럴 때 찾아보세요
새로운 콘텐츠의 등장을 조금 더 역동적으로 보여주고 싶을 때
현재 콘텐츠는 유지하고 주요 영역이 아래쪽 또는 옆에서 자연스럽게 들어오는 슬라이드인 효과를 추가해줘. 움직임은 짧고 부드럽게 해줘.
움직임·효과

스크롤 등장

Scroll Reveal

페이지를 아래로 내렸을 때 화면에 들어오는 콘텐츠가 순서대로 나타나는 효과입니다.

이럴 때 찾아보세요
긴 소개 페이지에서 영역별 콘텐츠의 흐름을 강조하고 싶을 때
현재 콘텐츠와 디자인은 유지하고 스크롤할 때 각 주요 콘텐츠 영역이 화면에 들어오면 자연스럽게 나타나는 효과를 추가해줘. 반복해서 과하게 움직이지 않게 해줘.
움직임·효과

부드러운 스크롤

Smooth Scroll

메뉴나 링크를 눌렀을 때 목적 위치로 갑자기 이동하지 않고 부드럽게 이동하는 효과입니다.

이럴 때 찾아보세요
상단 메뉴로 한 페이지 안의 여러 영역을 이동할 때
기존 메뉴 연결 기능은 유지하고 상단 메뉴를 누르면 해당 콘텐츠 영역으로 부드럽게 이동하는 스크롤 효과를 추가해줘.
움직임·효과

전환 효과

Transition

색, 크기, 위치 같은 상태 변화가 갑자기 바뀌지 않고 자연스럽게 이어지도록 만드는 효과입니다.

이럴 때 찾아보세요
버튼이나 카드의 변화가 딱딱하게 느껴질 때
현재 기능은 유지하고 버튼과 카드의 색상, 크기, 그림자 변화가 자연스럽게 이어지도록 전환 효과를 추가해줘. 전환 시간은 짧고 편안하게 설정해줘.
움직임·효과

그림자 변화

Shadow Effect

카드나 버튼의 그림자가 변하면서 화면에서 조금 떠오르는 듯한 느낌을 주는 효과입니다.

이럴 때 찾아보세요
카드의 구분이나 마우스 반응을 더 분명하게 하고 싶을 때
현재 디자인은 유지하고 카드에 마우스를 올렸을 때 그림자가 조금 더 강조되도록 해줘. 너무 진하거나 무거운 그림자는 사용하지 마.
움직임·효과

버튼 눌림 효과

Press Effect

버튼을 클릭할 때 살짝 작아지거나 내려가면서 실제로 누르는 듯한 반응을 주는 효과입니다.
