📘 웹디자인 용어 + 바로 쓰는 프롬프트

구조

헤더

Header

웹사이트 맨 위쪽의 큰 영역입니다. 로고, 사이트 이름, 메뉴 등이 들어가는 경우가 많습니다.

이럴 때 찾아보세요
사이트 맨 위가 정리되지 않아 보일 때
현재 콘텐츠와 기능은 유지하고 웹사이트 상단 영역을 정리해줘. 사이트 이름과 이동 메뉴가 한눈에 들어오도록 배치해줘.
구조

상단 이동 메뉴

Navigation

사용자가 원하는 콘텐츠나 페이지로 이동할 수 있게 해주는 메뉴입니다.

이럴 때 찾아보세요
메뉴를 만들거나 이동이 제대로 되는지 점검할 때
현재 디자인은 유지하고 상단에 이동 메뉴를 만들어줘. 메뉴를 누르면 해당 콘텐츠로 실제 이동할 수 있게 연결해줘.
구조

첫 화면 대표 영역

Hero Section

웹사이트를 열었을 때 처음 크게 보이는 대표 영역입니다. 핵심 제목, 설명, 이미지 등이 들어갑니다.

이럴 때 찾아보세요
첫 화면이 밋밋하거나 핵심이 안 보일 때
현재 콘텐츠는 유지하고 첫 화면에서 핵심 제목과 설명이 먼저 눈에 들어오도록 대표 영역을 다시 구성해줘.
구조

콘텐츠 영역

Section

비슷한 내용을 하나의 덩어리로 묶은 영역입니다.

이럴 때 찾아보세요
내용이 뒤섞여 보일 때
현재 내용은 삭제하지 말고 비슷한 내용끼리 영역을 나눠서 읽기 쉽게 구성해줘.
구조

카드

Card

이미지, 제목, 설명 등을 하나의 작은 상자처럼 묶어 보여주는 방식입니다.

이럴 때 찾아보세요
여러 정보를 반복해서 깔끔하게 보여주고 싶을 때
현재 콘텐츠는 유지하고 반복되는 정보를 카드 형태로 정리해줘. 카드마다 제목과 설명이 쉽게 구분되게 해줘.
구조

행동 유도 영역

CTA

사용자에게 클릭, 신청, 문의, 더 보기 같은 행동을 유도하는 부분입니다.

이럴 때 찾아보세요
사용자가 다음에 무엇을 해야 할지 분명하게 만들 때
사용자가 다음 행동을 쉽게 알 수 있도록 필요한 위치에 행동 유도 버튼을 배치해줘. 불필요한 버튼은 추가하지 마.
구조

하단 영역

Footer

웹사이트 가장 아래쪽 영역입니다. 연락처, 저작권, 추가 링크 등이 들어갈 수 있습니다.

이럴 때 찾아보세요
페이지 끝을 정리하고 싶을 때
현재 디자인과 어울리게 웹사이트 하단 영역을 정리해줘. 꼭 필요한 정보만 간결하게 배치해줘.
디자인

배치

Layout

화면에서 제목, 이미지, 카드, 메뉴 같은 요소를 어디에 놓을지 정하는 방식입니다.

이럴 때 찾아보세요
화면 구성이 어수선할 때
현재 콘텐츠는 유지하고 전체 배치를 더 정돈되게 수정해줘. 중요한 내용이 먼저 보이도록 구성해줘.
디자인

정렬

Alignment

글자나 이미지의 시작선과 위치를 맞춰 화면을 정돈하는 것입니다.

이럴 때 찾아보세요
요소들이 삐뚤삐뚤하거나 어수선해 보일 때
현재 콘텐츠와 크기는 유지하고 제목, 본문, 카드의 정렬을 일관되게 맞춰줘.
디자인

중요도 표현

Visual Hierarchy

사용자가 무엇을 먼저 보고 다음에 무엇을 볼지 시선의 순서를 만드는 것입니다.

이럴 때 찾아보세요
모든 글자가 비슷해 무엇이 중요한지 모르겠을 때
가장 중요한 제목이 먼저 보이고 다음으로 설명과 세부 내용이 보이도록 글자 크기와 굵기, 간격을 조정해줘.
디자인

글자 디자인

Typography

글꼴, 글자 크기, 굵기, 줄 간격 등을 조절해 읽기 쉽고 분위기에 맞게 만드는 것입니다.

이럴 때 찾아보세요
글자가 촌스럽거나 읽기 힘들 때
현재 콘텐츠는 유지하고 제목과 본문의 글자 크기, 굵기, 줄 간격을 조정해서 읽기 편하게 만들어줘.
디자인

색상 조합

Color Palette

웹사이트에서 함께 사용할 주요 색상을 정한 조합입니다.

이럴 때 찾아보세요
색이 너무 많거나 통일감이 없을 때
현재 구조와 콘텐츠는 유지하고 전체 색상을 3~4개의 조화로운 색상 중심으로 정리해줘.
디자인

대비

Contrast

글자와 배경처럼 서로 다른 요소의 차이를 분명하게 만드는 것입니다.

이럴 때 찾아보세요
글자가 배경에 묻혀 잘 안 보일 때
현재 색상 분위기는 최대한 유지하면서 글자와 배경의 대비를 높여 내용을 더 잘 읽을 수 있게 수정해줘.
디자인

여백

Spacing

요소와 요소 사이의 공간을 조절하는 개념입니다.

이럴 때 찾아보세요
전체적으로 화면이 답답해 보일 때
현재 콘텐츠는 유지하고 각 영역과 요소 사이의 여백을 조금 더 넓혀 답답하지 않게 만들어줘.
디자인

빈 공간

Whitespace

아무것도 없는 공간을 의도적으로 남겨 내용이 편하게 보이도록 하는 것입니다.

이럴 때 찾아보세요
화면에 너무 많은 것이 붙어 있을 때
현재 콘텐츠는 삭제하지 말고 요소 사이에 충분한 빈 공간을 만들어 핵심 내용에 집중할 수 있게 해줘.
디자인

바깥 여백

Margin

상자나 요소의 바깥쪽에 생기는 공간입니다.

이럴 때 찾아보세요
카드끼리 너무 붙어 있을 때
카드의 내용은 유지하고 카드와 카드 사이의 바깥 여백을 넓혀줘.
디자인

안쪽 여백

Padding

상자 테두리와 그 안의 글자나 이미지 사이의 공간입니다.

이럴 때 찾아보세요
카드 안 글자가 테두리에 너무 붙어 있을 때
카드 크기와 내용은 최대한 유지하고 카드 안쪽 여백을 조금 넓혀줘.
효과

글래스모피즘

Glassmorphism

반투명한 유리판이 겹쳐진 것처럼 보이는 디자인 스타일입니다.

이럴 때 찾아보세요
카드나 영역에 투명하고 현대적인 느낌을 주고 싶을 때
현재 콘텐츠는 유지하고 카드 영역을 반투명한 유리 느낌의 글래스모피즘 스타일로 바꿔줘. 글자는 잘 읽히게 해줘.
효과

움직임 효과

Animation

요소가 움직이거나 변하는 시각적 효과입니다.

이럴 때 찾아보세요
화면에 자연스러운 움직임을 더하고 싶을 때
현재 기능과 디자인은 유지하고 주요 요소에 자연스러운 움직임 효과를 추가해줘. 너무 빠르거나 과한 움직임은 사용하지 마.
효과

서서히 나타나기

Fade-in

요소가 갑자기 나타나지 않고 점점 선명해지는 효과입니다.

이럴 때 찾아보세요
페이지를 열거나 스크롤할 때 부드러운 느낌을 줄 때
현재 콘텐츠와 디자인은 유지하고 주요 콘텐츠가 자연스럽게 서서히 나타나는 효과를 추가해줘. 움직임은 과하지 않게 해줘.
반응형

반응형 웹디자인

Responsive Design

PC, 태블릿, 스마트폰처럼 화면 크기가 달라져도 보기 편하도록 배치와 크기를 조정하는 방식입니다.

이럴 때 찾아보세요
PC에서는 괜찮은데 스마트폰에서 화면이 깨질 때
현재 PC 디자인은 최대한 유지하고 스마트폰에서도 보기 편하도록 반응형으로 수정해줘. 메뉴, 글자, 이미지, 카드, 좌우 여백을 점검해줘.
반응형

화면 전환 기준

Breakpoint

화면 너비 등에 따라 배치를 바꾸기 시작하는 기준점입니다. 특정 숫자 하나가 모든 사이트의 정답은 아닙니다.

이럴 때 찾아보세요
어느 화면 크기부터 카드나 메뉴 배치를 바꿀지 정할 때
현재 디자인을 점검해서 콘텐츠가 불편해지는 화면 너비를 기준으로 필요한 배치가 자연스럽게 바뀌도록 해줘.
반응형

화면 조건별 스타일

Media Query

화면 크기 같은 조건에 따라 다른 CSS 스타일을 적용하는 방법 중 하나입니다.

이럴 때 찾아보세요
AI가 반응형 화면을 어떻게 구현했는지 이해할 때
현재 기능은 유지하고 작은 화면에서 필요한 부분만 조정해줘. 필요하다면 화면 크기에 따른 CSS 스타일을 적용해줘.
용어를 몰라도 괜찮습니다.
